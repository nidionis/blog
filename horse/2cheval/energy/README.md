# Energy — Version française (sous-projet 2Cheval)

> **Status:** canonical hub · **Owns:** heat sources · **Up:** [2Cheval](../README.md)

Cette couche répond à une seule question : d'où vient la chaleur ? La source de référence est la paille brûlée dans un rocket stove. La variante nucléaire est exploratoire et documentée séparément.

- [Rocket stove](rocket-stove/README.md) — paille, injection, combustion.
- [Variante nucléaire](nuclear/README.md) — source de chaleur spéculative.

La source de chaleur fournit la puissance thermique ; le moteur la convertit. À la base de 5 %, un moteur de **2 ch** a besoin d'environ **29,4 kW thermiques**. Voir [consommation de carburant](../engines/manson/fuel.md).
