# Injection de paille

> **Status:** exploratory · **Owns:** concept d'injection · **Up:** [Rocket stove](README.md) · **Lang:** FR · [EN](../../../energy/rocket-stove/injection.md)

Objectif : une injection homogène de paille dans le rocket stove. La note d'origine utilise le « vapour-horse » (`vh`) comme unité de communication, pas comme débit physique. La discussion complète est dans la [page anglaise](../../../energy/rocket-stove/injection.md).

> 16 – 72 vh  
> using an homogeneous injection  
> of 2 / 0.05 = 40 Vaporhorse an hour  
> is a desired to get the efficiency of 2 horses  
> as marketing purpose

Le débit réel pour une puissance donnée est dans [carburant](../../engines/manson/fuel.md) ; les propriétés sont dans [paille](straw.md). Une alimentation régulière est la condition d'un `P_th` stable ; l'irrégularité se traduit directement en fluctuation de puissance.
