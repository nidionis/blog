# Variante nucléaire — Version française (sous-projet 2Cheval)

> **Status:** exploratory / speculative · **Owns:** nuclear heat-source variant · **Up:** [2Cheval](../../../README.md)

Une source nucléaire pourrait remplacer la paille comme entrée de chaleur du [M Reloaded](../../engines/manson/README.md). L'échelle intéressante est petite : environ **1 à 12 ch**, pas une centrale. Ce n'est pas une étude de sûreté.

Toute conception réelle exige un spécialiste en radioprotection et une analyse de sûreté réglementaire.

## Points canoniques

- **Échelle de puissance :** 4 ch ≈ 3 kW mécaniques. À 5 % cela fait ~59 kW thermiques ; à 15 % optimisé, ~20 kW. Voir [échelle de puissance](power-scale.md).
- **Blindage :** 30 cm de plomb est la valeur de travail pour le gamma ; l'ancienne valeur de 20 cm est dépassée.
- **Neutrons :** le plomb seul ne suffit pas pour les neutrons rapides ; un matériau hydrogéné est nécessaire. C'est le facteur limitant pour une source de fission.
- **Géométrie :** le piston/échangeur de Manson doit tenir dans l'enveloppe de [dimensionnement](../../engines/manson/sizing.md); la source nucléaire ne change pas le dimensionnement du moteur.
