# Polar slicer — Prototype — Version française (sous-projet 2Cheval)

> **Status:** prototype · **Owns:** slicer status and limitations · **Up:** [Hub Polar slicer](README.md)

Générateur de G-code maison, optimisé pour les cylindres. Il peut échouer sur des formes complexes ; utiliser Cura dans ce cas.

Dépôt : [nidionis/polar-slicer](https://github.com/nidionis/polar-slicer)

- Générateur de G-code maison.
- Optimisé pour les pièces cylindriques.
- Peut buguer sur des formes complexes ; utiliser Cura alors.

Le modèle géométrique est dans [grille polaire](polar-grid.md) ; la limite de collision centrale est dérivée dans [limite angulaire](angular-limit.md).
