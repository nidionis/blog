# Moteurs — conversion chaleur → mouvement

> **Status:** canonical hub · **Owns:** conversion chaleur-mouvement · **Up:** [2Cheval](../README.md) · **Lang:** FR · [EN](../../engines/README.md)

Cette couche transforme la chaleur en mouvement. Le **M Reloaded** est le moteur choisi : cycle ouvert, pression atmosphérique, construction simple. Le **Stirling Beta** est une alternative étudiée : cycle fermé, gaz sous pression.

- [M Reloaded](manson/README.md) — moteur choisi : dimensionnement, carburant, puissance air, thermodynamique, optimisation, coûts, CAO.
- [Stirling Beta](stirling/README.md) — alternative étudiée, non choisie.
- [Leviers](../leviers/README.md) — pression, température, fréquence, volume, rendement.
- [Résilience](../business/resilience.md) — pourquoi le moteur simple est le bon compromis.

Ne pas mélanger les hypothèses des deux moteurs.
