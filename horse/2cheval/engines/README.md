# Engines — Version française (sous-projet 2Cheval)

> **Status:** canonical hub · **Owns:** heat-to-motion conversion · **Up:** [2Cheval](../README.md)

Cette couche transforme la chaleur en mouvement. Le **M Reloaded** est le moteur choisi : cycle ouvert, pression atmosphérique, construction simple. Le **Stirling Beta** est une alternative étudiée : cycle fermé, gaz sous pression.

- [M Reloaded](manson/README.md) — moteur choisi, dimensionnement, carburant, thermodynamique, optimisation, coûts, CAO.
- [Stirling Beta](stirling/README.md) — alternative étudiée, non choisie.

Ne pas mélanger les hypothèses des deux moteurs.
