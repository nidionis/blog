# Engines / Moteurs

> **Status:** canonical hub · **Owns:** heat-to-motion conversion · **Up:** [2Cheval](../README.md)

**FR** — Cette couche transforme la chaleur en mouvement. Le **Manson** est le moteur choisi : cycle ouvert, pression atmosphérique, construction simple. Le **Stirling Beta** est une alternative étudiée, fermée et pressurisée.  
**EN** — This layer turns heat into motion. The **Manson** is the chosen engine: open cycle, atmospheric pressure, simple construction. The **Stirling Beta** is a studied alternative: closed cycle, pressurised gas.

- [Manson / Manson](manson/README.md) — chosen engine, sizing, fuel, thermodynamics, optimisation, costs, CAD.
- [Stirling Beta / Stirling Beta](stirling/README.md) — studied alternative, not chosen.

Do not mix the assumptions of the two engines / Ne pas mélanger les hypothèses des deux moteurs.
