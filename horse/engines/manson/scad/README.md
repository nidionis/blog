# Manson CAD model / Modèle CAO Manson

> **Status:** illustrative · **Up:** [Manson](../README.md)

**FR** — `piston.scad` est une esquisse paramétrique, pas un plan de production. Le modèle utilise `inner_r = 70` (millimètres) et une unité géométrique appelée `chink` ; il n'est pas à l'échelle du moteur complet.  
**EN** — `piston.scad` is a parametric sketch, not a production drawing. It uses `inner_r = 70` (millimetres) and a geometric unit called `chink`; it is not scaled to the full-size engine.

- [`piston.scad`](piston.scad) — parametric sketch of a potential Manson piston and chamber.
- [`manson.stl`](manson.stl) — exported mesh.

Full-size volumes and diameters are in [sizing](../sizing.md).  
Les volumes et diamètres réels sont dans [dimensionnement](../sizing.md).
