# Manson CAD model

> **Status:** illustrative · **Up:** [README](../README.md)

`piston.scad` is a parametric sketch, not a production drawing. It uses `inner_r = 70` (millimetres) and a geometric unit called `chink`; it is not scaled to the full-size engine.

- [`piston.scad`](piston.scad) — parametric sketch of a potential Manson piston and chamber.
- [`manson.stl`](manson.stl) — exported mesh.

Full-size volumes and diameters are in [sizing](../sizing.md).
