# Stirling Beta — studied alternative / alternative étudiée

> **Status:** exploratory hub · **Owns:** alternative engine study · **Up:** [2Cheval](../../README.md)

**FR** — Le Stirling Beta est une alternative **à cycle fermé**, étudiée avec de l'azote et un alternateur linéaire. Ce n'est **pas** le moteur choisi : le [Manson](../manson/README.md) est plus simple à construire et fonctionne en cycle ouvert.  
**EN** — The Stirling Beta is a **closed-cycle** alternative, studied with nitrogen and a linear alternator. It is **not** the chosen engine: the [Manson](../manson/README.md) is simpler to build and uses an open cycle.

Do not mix these assumptions with the Manson numbers. / Ne pas mélanger ces hypothèses avec les chiffres du Manson.

- [Beta sizing / Dimensionnement Beta](beta-sizing.md) — volume, frequency, pressure and ΔT study.
- [Linear alternator / Alternateur linéaire](linear-alternator.md) — magnet/coil ranges and control.
- [Raw notes / Notes sources](notes/) — source derivations and links.

## Why keep it / Pourquoi le garder

The Stirling study is useful as a comparison: closed cycle, pressurised gas, higher complexity, possible linear generator. It documents what was considered and why the Manson was preferred.  
L'étude Stirling sert de comparaison : cycle fermé, gaz sous pression, complexité plus élevée, générateur linéaire possible. Elle documente ce qui a été envisagé et pourquoi le Manson a été préféré.
