# Polar slicer

> **Status:** canonical hub · **Owns:** slicing software · **Up:** [2Cheval](../../README.md)

The polar slicer is a homemade G-code generator optimised for cylinders. It is a prototype: it can fail on complex shapes, in which case Cura is the fallback.

- [Prototype status](prototype.md) — status and limitations.
- [Polar grid geometry](polar-grid.md) — how the polar lines are laid out.
- [Angular limit](angular-limit.md) — minimum stopping radius near the centre.
