> **Status:** prototype · **Owns:** slicer status and limitations · **Up:** [Polar slicer hub](README.md)

**FR** — Générateur de G-code maison, optimisé pour les cylindres. Il peut échouer sur des formes complexes ; utiliser Cura dans ce cas.  
**EN** — Homemade G-code generator, optimised for cylinders. It can fail on complex shapes; use Cura in that case.

Repository / Dépôt : [nidionis/polar-slicer](https://github.com/nidionis/polar-slicer)

- Can bug on complex shapes; in that case use Cura / Peut buguer sur des formes complexes ; utiliser Cura alors.
