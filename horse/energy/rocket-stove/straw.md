# Straw properties / Propriétés de la paille

> **Status:** canonical · **Owns:** fuel properties · **Up:** [Rocket stove](README.md)

**FR** — La paille est le carburant de référence. Le PCI et les densités ci-dessous sont les seules valeurs à réutiliser ; la consommation dépend du moteur et se trouve dans [fuel](../../engines/manson/fuel.md).  
**EN** — Straw is the reference fuel. The LHV and densities below are the only values to reuse; consumption depends on the engine and lives in [fuel](../../engines/manson/fuel.md).

| Property / Propriété | Value / Valeur |
|---|---:|
| Lower heating value (LHV / PCI) | **15 MJ/kg** |
| Bulk density, loose / densité en vrac | **~100 kg/m³** |
| Bulk density, densified / densité densifiée | **~250 kg/m³** |

For a 10 min run at 2 ch, the baseline consumption is about **1.2 kg of straw**; see the derivation in [fuel](../../engines/manson/fuel.md).  
Pour un essai de 10 min à 2 ch, la consommation de base est d'environ **1,2 kg de paille** ; voir la dérivation dans [fuel](../../engines/manson/fuel.md).
