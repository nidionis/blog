# Straw properties

> **Status:** canonical · **Owns:** fuel properties · **Up:** [Rocket stove](README.md)

Straw is the reference fuel. The LHV and densities below are the only values to reuse; consumption depends on the engine and lives in [fuel](../../engines/manson/fuel.md).

| Property | Value |
|---|---:|
| Lower heating value (LHV) | **15 MJ/kg** |
| Bulk density, loose | **~100 kg/m³** |
| Bulk density, densified | **~250 kg/m³** |

For a 10 min run at 2 ch, the baseline consumption is about **1.2 kg of straw**; see the derivation in [fuel](../../engines/manson/fuel.md).
