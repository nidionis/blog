# Straw properties

> **Status:** canonical · **Owns:** fuel properties · **Up:** [Rocket stove](README.md) · **Lang:** EN · [FR](../../2cheval/energy/rocket-stove/straw.md)

Straw is the reference fuel. The LHV and densities below are the only values to reuse; consumption depends on the engine and lives in [fuel](../../engines/manson/fuel.md). The full biomass table is in [biomass calorific capacity](biomass-calorific.md).

| Property | Value |
|---|---:|
| Lower heating value (LHV) | **12 MJ/kg** (low baseline; table range 12.5–14.5) |
| Bulk density, loose | **~100 kg/m³** |
| Bulk density, densified | **~250 kg/m³** |

The 12 MJ/kg value is below the low end of the straw range (12.5–14.5 MJ/kg), chosen to harden the calculations. The previous 15 MJ/kg value was optimistic and is no longer used.

For a 10 min run at 2 ch, the baseline consumption is about **1.5 kg of straw**; see the derivation in [fuel](../../engines/manson/fuel.md).
