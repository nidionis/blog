# Energy / Énergie

> **Status:** canonical hub · **Owns:** heat sources · **Up:** [2Cheval](../README.md)

**FR** — Cette couche répond à une seule question : d'où vient la chaleur ? La source de référence est la paille brûlée dans un rocket stove. La variante nucléaire est exploratoire et documentée séparément.  
**EN** — This layer answers one question: where does the heat come from? The reference source is straw burned in a rocket stove. The nuclear variant is exploratory and documented separately.

- [Rocket stove / Rocket stove](rocket-stove/README.md) — straw, injection, combustion.
- [Nuclear variant / Variante nucléaire](nuclear/README.md) — speculative heat source.

The heat source supplies thermal power; the engine converts it. At the 5 % baseline, a **2 ch** engine needs about **29.4 kW thermal**. See [fuel consumption](../engines/manson/fuel.md).
