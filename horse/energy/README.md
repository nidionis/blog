# Energy

> **Status:** canonical hub · **Owns:** heat sources · **Up:** [2Cheval](../README.md)

This layer answers one question: where does the heat come from? The reference source is straw burned in a rocket stove. The nuclear variant is exploratory and documented separately.

- [Rocket stove](rocket-stove/README.md) — straw, injection, combustion.
- [Nuclear variant](nuclear/README.md) — speculative heat source.

The heat source supplies thermal power; the engine converts it. At the 5 % baseline, a **2 ch** engine needs about **29.4 kW thermal**. See [fuel consumption](../engines/manson/fuel.md).
